# spotpear-scratch.github.io

This is the repository for the OpenBlocks Scratch tool and documentation wiki that supports the Spotpear C3 MiniTV Keychain/
Please see the wiki for more information about how to edit and load this board with the firmware that allows it to be used
with this device.
